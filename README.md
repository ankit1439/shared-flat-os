# Shared Flat OS

Website for four roommates: Ankit, Jayash, Rahul, Lakshit.

## Run locally

```bash
npm install
npm run db:setup
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) on your phone or laptop browser.

1. Tap **who you are**
2. Use Home / Money / Flat / People

This is a **website**, not an App Store / Play Store app.
